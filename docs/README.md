## 当前路径约定

| 内容 | 路径 |
|---|---|
| 测试程序 | `automation/*.py` |
| 运行配置 | `automation/config.json` |
| 业务测试资料 | 仓库根目录下的 `.doc`、`.docx`、`.txt`、`.xlsx` |
| 常规测试结果 | `模型测评结果/` |
| Linux 历史场景结果 | `Linux测试结果/` |
| 本地迁移备份 | `local-backup/` |

业务资料、测试结果和本地备份均由 `.gitignore` 排除。`docs/` 中不得写入 API 密钥、内部接口地址或未脱敏业务正文。

## 已知资料缺口

现有资料缺少“公司合规管理制度（约 10000 字）”。依赖该文档的 `missing_compliance` 和部分历史场景会标记为缺资料；这不是程序读取路径错误。补充真实对应文档后，将文件放到仓库根目录即可被测试程序发现。
