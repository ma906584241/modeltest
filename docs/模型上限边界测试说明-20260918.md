# DeepSeek14B 上限边界测试说明

## 测试目标

报告会分别给出：

- 最大稳定输入 token
- 最大稳定输出 token
- 最大稳定上下文长度（输入 token + 输出 token）

这些值表示本次配置、提示词、超时和重复次数下的最大稳定档位，不等同于模型或服务的理论极限。

## 执行命令

将完整 `modeltest` 目录放到 Linux 服务器，进入仓库根目录后执行：

```bash
cd /path/to/modeltest
python3 automation/run_tests.py --mode limits --model deepseek14b
```

功能、容量和边界完整测试执行：

```bash
python3 automation/run_tests.py --mode full --model deepseek14b
```

固定汇总报告：

```text
模型测评结果/report.html
```

## 测试档位

默认配置为：

```text
输出：8192、16384、32768
输入：8192、16384、24576、32768
上下文：输入16384+输出4096、输入24576+输出4096、输入32768+输出4096、输入32768+输出16384
```

以上档位来自当前 `automation/config.json`。当前 `limit_concurrency_levels` 和 `extended_concurrency_levels` 均为空，本说明不包含并发边界测试。

## 判定方法

`finish_reason=length` 且 `completion_tokens` 接近 `requested_max_tokens`，才表示触达本次生成上限；`stop` 只表示模型提前结束，不能证明达到上限。

输入和上下文边界以服务返回的 `usage.prompt_tokens`、`usage.total_tokens` 为准，不以字符数代替 token 数。最大稳定值要求该档位的所有重复请求成功，无 `TIMEOUT`、`ERROR` 或显存错误。

## 服务器配置注意事项

当前客户端配置声明：`max_input_token_len=32768`、`max_seq_len=65536`、`max_iter_times=32768`。这些值必须与实际服务端配置一致。32768 token 输出即使在长度配置上允许，也可能受客户端或服务端超时限制；超时只能说明请求未在规定时间内完成，不能直接当作模型 token 上限。
